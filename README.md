# Case Filing Process Flowchart

This repository contains an interactive flowchart for the Dubai Courts case filing process.

## Files:
- `index.html` - Complete interactive flowchart with documentation
- `flowchart.html` - Large flowchart optimized for viewing and printing
- `Case_Filing_Process_Flowchart.md` - Markdown version with tables and text

## Usage:
Visit the deployed site to view the interactive flowchart.

## Features:
- Interactive flowchart with zoom controls
- Print-friendly PDF export
- SVG download capability
- Mobile responsive design
- Professional styling for client presentations
